# Headless font metrics

These are complete `Glyphs.lua` snapshots generated by the real Windows GDI
tool from the project's Noto Sans SC/JP/KR VF fonts at 32 px. They preserve the
actual advances, glyph bounds and atlas coordinates used by the layout,
cursor, wrapping and language selector regressions. Font copyright and OFL
notices are in `docs/licenses/NotoSans{SC,JP,KR}-OFL.txt` at the repository root.

Regenerate on Windows from the repository root, using the bundled fonts:

```cmd
build.cmd --all-fonts
python tools/check-atlas.py --all
python tools/export-localisation-font-metrics.py
```

Review `sources.json` and the changed metrics together. The exporter records
font, generator and metrics hashes. Do not use a `NOTO_SANS_SC_FONT` override
when updating fixtures. Windows checks compare freshly generated metrics with
these snapshots so font or generator changes require an explicit update.

The test setup replaces only font resource selection, using these versioned
metrics for every `Font.New` call. It runs the real layout/drawing code and all
existing assertions without invoking FontAtlas or consulting any user cache.
Image handles come from the existing headless SimpleGraphic host: these files
do not verify pixels, GDI availability, native windows or IME behavior.
The optional Windows job separately generates and validates actual atlas pages.
