# 动态技能、天赋授予技能及分段标题复查

本批按实际提示框先汇总再补译，简体修正或新增 91 条、繁体 108 条，共 199 条、128 个不同 key。逐项原文、原译、译文与原因见 [资源变更清单](localisation-dynamic-skill-changes-2026-10-31.csv)。新增译文为自译，未核实为官方文案。

## 根因与处理

966 个宝石在等级 1／自然上限（最多 20）、品质 0／20 下，以及当前 4,914 个天赋的实际提示框，共触及 2,305 个动态属性模板、3,447 组去重参数样本。稳定 key 已正确绑定，缺口主要来自中文资源缺项、旧反查的半句拼接、破损术语标记及已有误译。本批只修中文资源，不改 StatDescriber、游戏原文或计算身份。

修复内容包括辅助技能的非混沌伤害减量、血沸、分身强化、屏障、雄鹿、远古之花、尸体消耗、生命代替精魂保留、塔萨里奥律动，以及虫群敏捷加成误译成效果范围。另核对总增／总降方向、6／8 秒装填条件、1 米至 3.5 米的距离衰减、印记传播距离和点燃频率；保留已核实正确的荆棘消失变慢与复活更慢，不机械翻转全部增减候选。繁体命运技能的否定词漏译也已修正。

烈炎风暴两个分段标题原为“Ice 枚箭矢／發彈數Ice”等错误拼接，已改为冰霜箭矢、闪电箭矢／閃電箭矢，并核对实际提示框。

真实长中文说明还复现了超过 600 像素的情况：原换行只按空格分段，连续中文无法分行。现复用 Unicode 字形测宽，按字符及可用空格边界换行，保留 UTF-8、颜色码和逻辑分行；纯英文沿用原路径。没有加入中文标点禁则，个别末尾右括号仍可能独占一行，不声明原生排版已经完全验收。

- 独立 before／after 核对：7,632 份完整英文提示框文本与字体一致，2,305 个模板的 key、原文、拥有对象、英文参数及输出一致。此独立快照未正确记录行高；行高由永久往返回归单独覆盖。

- 三构筑对照通过：73,304 个英文输出／报告标量，139,906 个简繁计算输出标量。保留既有已核实的一处混沌护盾说明修正。
