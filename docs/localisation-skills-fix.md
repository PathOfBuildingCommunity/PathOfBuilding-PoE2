# 技能名称与描述汉化修复

日期：2026-10-30。工作目录：`E:\PathOfBuilding-PoE2`。

## 问题与根因

用户截图中的 `Fulminating Concoction` 在技能槽中保留英文，提示框标题却显示“雷鸣灵药”。技能槽继承 `EditControl` 的原文绘制行为，未提供已识别技能的非编辑显示文本。原文保护本身用于保持输入、光标和保存内容，不能全局取消。

技能提示框已经通过稳定 key 读取描述、标签和武器需求，但中文 `Game.csv` 缺少所有 1,095 个技能描述字段，以及大量组合标签等资源。提示框的部分 `Messages.csv` 模板也仍是英文或中英混排，因此会同时出现中文标题与英文正文、`Cost`、`Unarmed`、`% of 基础`。

## 修改

- `SkillsTab.lua` 为技能名称控件提供现有 `inactiveText` 回调。仅当缓冲区等于该槽位已识别技能的名称时，使用 `localisation:SkillName` 显示；进入编辑后仍使用原缓冲区。未识别、自定义输入保持原文。
- 简体、繁体各补齐 1,095 个技能描述，并补齐缺少的技能名称、子效果名称、宝石类型、标签组合、武器需求和辅助类别显示资源。
- 新增游戏显示资源：简体 2,535 条、繁体 2,428 条。原有游戏译文没有被替换；不修改英文资源、技能 ID、原始名称、数值或计算源码。
- 各修正 32 条技能选择和宝石提示模板，保留命名参数、格式与颜色码，覆盖消耗、保留、攻击速度和伤害、最高等级、品质、腐化及构筑备注提示。
- 清理繁体来源描述中残留的游戏关键字标记和混入的英文 `Minions`，保留合法的 `X` 型范围符号。

## 描述来源

来源对应表见 [localisation-skill-sources.csv](localisation-skill-sources.csv)，每条记录保留稳定 key、英文 SHA-256、匹配方式和中英来源位置。

- 957 个描述字段与 PoE2DB 的英文技能或辅助技能列表逐字匹配后使用对应简繁译文；匹配仅归一化布局空白。各字段仍使用自身的稳定 key，没有合并业务身份。
- 138 个描述字段不满足上述匹配条件，按本仓库当前英文翻译，覆盖 116 段不同正文，包括触发子技能、弩箭发射效果与怪物技能。正文引用的专名与现有技能译名对齐；这些补译不宣称经过官方术语审校。
- 对照检查数字差异：差异均来自英文数字单词或单数冠词与中文阿拉伯数字之间的等价表达，没有借用不同版本的英文描述。
- 新增标签术语按同一列表中的标签身份核对；已有术语沿用项目译名。

## 既有译名复核

用户要求专名沿用已有翻译。复核以修改前的 `Game.csv` 和仓库原有 `Items_Gems.txt.csv`、`Gems_data.txt.csv` 等为依据；外部描述中的专名也要与当前工程对齐。

- 比较英文名称时检查重音符号差异，确认 `Morrigan` / `Mórrigan`、`Oisin` / `Oisín` 对应同名技能。简体沿用“莫丽根的洞察”“奥辛之誓”，繁体沿用“莫里根的洞察”“歐辛的誓言”。
- 人物、地域与材料沿用既有名称：简体“卡古兰的乌崔德”“维金”，繁体“卡爾葛的烏特雷”“維里西姆”。
- 描述引用的魔侍冰霜法师、镇魂曲、卡哈塔的复苏、深渊幻象等沿用现有字段；钙质碎片辅助触发的效果使用“钙质碎片爆破”。“破碎拟像”是触发技能名，“分裂拟态”是生成物名，按英文身份分别处理。
- 同时对齐有现有数值词条佐证的浸湿、定身、魂井之灵、撕裂护甲、虚弱层数等术语。仅修订本次新增资源，未覆盖项目原有译文。
- 发现繁体群星回应的来源中文仍描述旧版彗星效果，按仓库当前英文重译，并引用既有“星墜”名称。英文来源逐字匹配不等于其中文正文一定同步更新。

逐项修订与证据见 [localisation-skill-terminology.csv](localisation-skill-terminology.csv)。描述来源表新增 `zh_cn_review` / `zh_tw_review`，分别标记术语对齐与依据当前英文重译的条目。其余来源译文保留原来源记录，不将本次检查描述为官方术语审校。
