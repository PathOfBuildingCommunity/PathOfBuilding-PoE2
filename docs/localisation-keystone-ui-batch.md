# 传奇天赋与常用界面补译记录

日期：2026-10-31。范围为用户截图中的传奇天赋描述、珠宝范围附加属性及常用界面漏译；完整中文化目标继续开放。

## 根因与修改

- 凝心者的名称、属性和风味文本分别通过稳定 key 显示。英文 `Game.csv` 已有 `game.tree_node.0_5_34497.flavour_text`，简繁资源缺失，导致橙色风味文本回退英文。没有修改天赋计算或节点原始数据。
- 0.4、0.5 每版均有 33 个带风味文本的传奇天赋，两个版本的英文描述相同。简繁 `Game.csv` 各补 66 个 key；多行描述保持原文换行数量。
- 珠宝范围附加属性的简繁资源各补录或修正 215 条，其中新增 27 条。珠宝范围标签在提示框使用已有字段引用，Very Large 显示为“极大型／極大型”。
- 从 625 条常用界面候选中补译简体 416 条、繁体 574 条；该统计仅包含候选最初缺失的语言，不包含本次新增的 10 个上下文 key，也不代表全项目覆盖率。
- 修正动态组合中的英文片段：跨页面装备提示、授予技能的单复数提示、配置比较动作、野兽与幽魂库标题。使用现有 `Ref`/`Label` 与完整模板，不修改列表身份、技能身份或计算参数。

## 属性详情弹窗补译（2026-10-31）

用户连续截图报告暴击率、攻击速度和有效承伤池的局部英文。用仓库 `resurrectgodaura.xml` 真实构筑和 `CalcBreakdownControl` 复现最初截图：基础暴击率 `(12.53 + 3.3)`、增幅 `2.84`、额外倍率 `2.02`、结果 `90.63%`，对应的 `Weapon Set 2`、`Hit, Spear`、`If Power Charges >= 1, Buff` 同时出现。

根因及限定修复：

- 计算报告已经使用稳定 key，但简体/繁体的通用增减模板和部分公式说明仍为英文；补译已审核的同类增减模板、暴击率基础/结果、简体有效承伤池四条说明及攻速/施法速率单位。攻击与施法共用的 `line_40` 原资源为 `casts 每秒`，中文统一使用适用于两者的“次/秒”，英文原文保持。
- 表格直接输出位标志和条件变量身份；`Terms.lua` 显式登记当前 ModFlag/KeywordFlag 全部 57 个不同身份，以及武器组、充能球、药剂条件、暴击率和增益术语。只转换显示字符串，标志位、修饰词、条件、阈值和来源身份保持。条件列表逐项转换，未知身份沿用原拆词回退。
- 来源分类和总计提示改用既有 calculation_source 显示术语域；稀有装备导入标题 `Pain Caress`、`Maelstrom Star` 保持原文。没有可靠对应译名时不生成替代物品名。
- 暴击率基础的主手武器来源后缀改为独立资源。三语各新增 78 个稳定资源 key。中文术语优先对齐本地装备类型和技能标签资源，其余为项目界面补译。

`Tests/LocalisationStatPopup.lua` 关闭旧 Translate 反查，在 English → 简体 → 繁体 → English 中验证真实暴击率公式、全部位标志、表格绘制文本、原修饰词身份与数值、药剂攻速条件、共用速率单位、有效承伤池公式和未知名称回退。新增回归在修复前分别失败于中文基础暴击率公式以及 `casts 每秒` 残留。
