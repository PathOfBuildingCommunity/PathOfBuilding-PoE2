# Windows 多语言便携预发布

## 目标与边界

按用户确认，发布当前多语言分支的 Windows 便携 ZIP 预发布版；标签采用上游最新正式版号加多语言标记。2026-10-31 核实上游最新正式版为 v0.23.1，本次标签为 v0.23.1-multilingual.1。

发布到 isWxiang/PathOfBuilding-PoE2。包含运行库、游戏资源、翻译、字体、字体生成器和许可证，玩家无需 Git、Python、Node.js 或编译器即可运行。英文、简体中文、繁体中文可用；日语和韩语入口目前回退英文。此分支基于上游 dev，版本标记不表示只包含上游正式版代码。

## 发布决定

- 采用应用既有的独立便携布局，程序、Lua 和资源位于同一目录，构筑与设置保存在解压目录。
- 使用干净 Git 快照构建字体工具及中文图集，排除个人设置、构筑、日志、测试和开发工具。
- 采用本次 release 的固定 manifest 与 ZIP 作为完整性检查和恢复来源，不追踪上游自动更新；新版由玩家下载新的 ZIP。
- 发布 ZIP、manifest.xml、SHA256SUMS.txt，并更正本仓库 README 下载入口。

## 验收与恢复

验证 ZIP 完整性、清单中全部文件的哈希、所需字体与许可证，运行已有本地化检查，并实际启动解压后的便携程序、检查语言切换、构筑保存和更新结果。

发布前先创建草稿并上传全部附件，最后设为预发布。失败时保留本地产物和证据；已发布版本需要更正时发布新标签，避免静默覆盖玩家已经下载的二进制包。
